# Backup and Disaster Recovery Roadmap

## Current State

RAID 5 provides single-drive fault tolerance for the UNAS Pro.

RAID is not a backup strategy.

A formal backup and disaster-recovery architecture is still being developed.

## Goals

- Data protection
- VM and container recovery
- Configuration recovery
- Off-site protection
- Retention policy
- Restore testing
- Recovery priorities
- Backup monitoring

## Areas to Define

- Critical application data
- Infrastructure configuration
- Virtual machines
- Containers
- Docker configuration
- Databases
- Automation configuration
- Home Assistant configuration
- Git repositories not already hosted remotely

## Restore Testing

Backups should be proven through actual restore exercises.
