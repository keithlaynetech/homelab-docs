# Observability

Observability answers:

> Why is the environment behaving this way?

## Core Components

- Grafana
- Loki
- Prometheus
- VictoriaMetrics

## Capabilities

- Historical analysis
- Centralized logs
- Dependency awareness
- Event correlation
- Root-cause investigation

Troubleshooting accounts for dependencies such as DNS, storage, networking, authentication, databases, reverse proxy, and host health.

## Future AI Integration

The planned AI agent will use monitoring and observability data as read-only context before controlled operational actions are introduced.
